# Changelog

## 0.4.1 - 2026-10-16

- Documentation: a demo of real output at the top of the README, a security policy, a changelog, and issue templates.

- Windows fixes.

## 0.1.0 - 2026-09-09

- First release: fetch, extract, store and full-text search, plus one-click capture.
